## 1. 产品概述

### 1.1 产品定位

Wooper RPA Script Editor 是一款低代码/无代码的RPA（机器人流程自动化）脚本编辑器，基于 Playwright 引擎，支持 Web 应用和桌面应用的自动化操作。产品提供三种流程创建方式：**录屏识别**、**自然语言生成**、**可视化拖拽**，并集成 AI Copilot 实现智能辅助编程。

### 1.2 产品愿景

让企业用户和个人开发者能够快速、高效地创建自动化流程，降低RPA开发门槛，提升业务流程自动化效率。

### 1.3 核心价值

- **低门槛**：非技术人员通过录屏和自然语言即可创建自动化流程
- **高效率**：可视化拖拽 + AI Copilot 大幅提升开发效率
- **跨平台**：同时支持 Web 和桌面应用自动化
- **可扩展**：丰富的预制组件库和自定义组件能力

|---------|------|---------|

  id: string;
  name: string;
  description: string;
  version: string;
  created: Date;
  updated: Date;

  // 节点
  nodes: Node[];

  // 连接
  edges: Edge[];

  // 全局变量
  variables: Variable[];

  // 配置
  config: FlowConfig;
}

// 节点
interface Node {
  id: string;
  type: string;  // 组件类型
  position: { x: number; y: number };
  data: {
    name: string;
    props: Record<string, any>;
    // ...
  };
}

interface Edge {

  source: string;
  target: string;
  sourceHandle?: string;
  targetHandle?: string;

}

### 6.1 性能要求

| 指标 | 目标值 |
|------|--------|
| 应用启动时间 | < 3秒 |
| 画布渲染(100节点) | < 100ms |
| 流程加载时间 | < 500ms |
| 录屏延迟 | < 50ms |
| AI响应时间 | < 2秒 |
| 内存占用 | < 500MB |

| 要求 | 说明 |
|------|------|
| 自动保存 | 每30秒自动保存，支持版本历史 |

| 数据备份 | 支持本地备份和云端同步 |
| 日志记录 | 完整的操作日志和错误日志 |

| 要求 | 说明 |
|------|------|

| 执行隔离 | 流程执行环境隔离 |
| 权限控制 | 企业版支持角色权限 |

### 6.4 兼容性要求

| 类型 | 支持范围 |
